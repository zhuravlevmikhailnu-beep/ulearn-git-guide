# S2. Коммиты

> История версий — дерево коммитов

> Коммиты неизменны, а хэш — идентификатор коммита

> Ничего, кроме исходников, не должно попадать в репозиторий

- `git add .` — добавить все изменённые файлы в индекс
- `git add -p <filename>` — выбрать изменения для добавления в индекс
- `git commit -m <msg>` — сохранить содержимое индекса в репозитории в виде коммита
- `git commit -am <msg>` — добавить изменения в уже известных файлах в индекс, затем сохранить содержимое индекса в виде коммита
- `git status -s` — вывести состояние каталога и индекса кратко с указанием текущей ветки
- `git restore --staged <file>` — отменить индексирование (вернуть файл из индекса в untracked/modified)
- `git rm <filename>` — удалить файл из каталога и индекса, чтобы перестать хранить его в репозитории
- `git show <commit>` — показать содержимое коммита
- `git diff <from_commit> [to_commit]` — вывести разницу между двумя коммитами
- `git diff --name-status <from_commit> [to_commit]` — список изменённых файлов
- `git difftool <from_commit> [to_commit]` — вывести разницу с помощью внешнего инструмента
